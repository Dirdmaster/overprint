# Inspector panels

The inspector has four task-specific tabs. Use the arrow keys, Home, or End while a tab is focused to switch panels. Switching panels preserves the selection and pending repeat preview. Undo and redo remain available below every panel.

- **Layers** contains Front and Back artboard stacks, selected artwork properties, native layer visibility, and the composition library.
- **Color** lists the actual fill and stroke colors in selected artwork. Edit them independently, use saved colors, or switch to Paint for individual regions. Project-wide replacement opens separately. See [Color](color.md).
- **Layout** controls snapping, centers selected artwork on PCB features, and previews line or circular repeats. Circular repeats show a radius; line repeats show X/Y spacing. Select artwork on the canvas or in Layers before aligning or repeating.
- **Board** contains PCB geometry, the printed background, print checks, PCB file updates, and recoverable PCB revisions. The printing profile remains available under **Printing rules**.

These panels are views of the same editor state. Switching tabs does not change the project or create an undo checkpoint.
