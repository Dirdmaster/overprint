# Composition library

In **Layers**, open **Library** to browse saved compositions as thumbnails. Select a tile for a larger preview, physical dimensions, and placement actions. Compositions containing both Front and Back artwork show both sides together.

**Place copy** creates independent editable artwork. **Place linked** keeps a snapshot pinned to its saved revision. Placed artwork stays in the project even if the original library entry is deleted. Library compositions are saved on this device and included in workspace backups.

To create a composition, open **From this board**. Click the artwork thumbnails to select graphics from Front, Back, or both. The current canvas selection is preselected, including graphics inside selected folders. Use **Select all** or **Clear**, enter a name, and choose **Save selection**. Saving returns to the gallery with the new composition selected.

Use **Manage composition** on the selected saved item to rename it, delete it, or save the current board selection as a new revision. Linked placements only update after **Check for updates**, preview, and **Apply update**. Copies remain independent.
