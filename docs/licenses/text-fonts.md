# Editable text font provenance

The following WOFF files are copied unchanged from the npm package `@fontsource/geist` version 5.3.0, from its `files/` directory. The original font project is https://github.com/vercel/geist-font. Fontsource packaging is https://github.com/fontsource/font-files/tree/main/fonts/google/geist.

The fonts retain their SIL Open Font License 1.1. The converter is OpenType.js 2.0.0 (MIT), pinned in both consuming packages and the lockfile. Full notices are retained in `apps/web/public/text-fonts/LICENSES.txt` and `packages/editor/THIRD_PARTY_NOTICES.txt` so they ship with both distributions. The editable font identifier is versioned separately from the UI label; changing fonts requires a new identifier. Stored outlines must never be regenerated during project import.
