# Framework integration

Each example below is the actual mounting code used by its live story. Select a story and open the **Code** panel to see and copy its source beside the editor.

The host creates a controller from its board data and owns persistence. Mounting and unmounting the view is separate from destroying the controller.

```js
import { createEditor } from '@overprint/editor'
import { mount } from './vue.js' // or react.js / vanilla.js below

const controller = createEditor(board, { mask: '#161616' })
const unmount = mount(document.querySelector('#editor'), controller)

// Host save / restore:
const saved = controller.getDocument()
await controller.restore(saved)

// When the host is finished with this editor:
unmount()
controller.destroy()
```

## Next.js (App Router)

Pass serializable board data from the server page to this client component. It imports the editor after hydration and disposes it on unmount or board replacement. Save and restore here use host memory; connect them to your own persistence as needed.

The live story runs this same client component in React Strict Mode. The page example shows where to mount it in a Next.js application.
