# LoRa dev card demo

This is a pre-extracted BoardPackage snapshot of the LoRa development card,
approved by its owner for public use in Overprint's Storybook on 2026-09-23.
It is distributed with this repository under its MIT license.

The snapshot was exported read-only from `loracard.kicad_pcb` on 2026-09-22
using KiCad's pcbnew API and the Overprint plugin's polygon/SVG helpers.
Source PCB SHA-256: `28fe523c65bf7330dbdf7a88d545912a076cae7928c12266ab9b2d0f8b0e2cd6`.

The board measures 70 by 35 mm. The snapshot retains both faces, copper,
solder mask, silkscreen, fabrication references and through holes. The demo
uses black solder mask. The native PCB and local source paths are not included.

This dense illustrated board exceeds the browser parser's current token limit.
The pre-extracted snapshot demonstrates host-supplied geometry; it is not proof
that the raw PCB can be imported in the browser or that fabrication is validated.
The refresh recipe reloads this same snapshot, not a different hardware revision.
